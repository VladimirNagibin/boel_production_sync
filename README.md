# boel_production_sync

Приложение для обработки и синхронизации данных между **Битрикс 24** и **1С**.

## Функционал

Основная задача приложения — **синхронизация и обработка сделок**, **платежей**, **накладных** и **формирование отчётов** на основе данных из CRM и ERP систем.

## Процесс формирования отчёта по сделкам

Для формирования отчёта по сделкам необходимо выполнить следующие шаги:

1. **Проверка сделок на воронку и удаление**
   Запустить endpoint: deals/check-deals

2. **Обновление/загрузка сделок**
   Загрузить актуальные данные по сделкам и добавить счета в очередь обработки: deals/load-deals

3. **Выгрузка данных из 1С**
В 1С запустить **выгрузку платежей и накладных**.

4. **Формирование отчёта**
В админке перейти в:
`Админка → Отчёты → Экспорт сделок`
или endpoint:  reports/export-deals

## Требования

- Python 3.11+
- Битрикс24 (с доступом к REST API)
- 1С (с настроенной выгрузкой)

## Установка

1. Клонируйте репозиторий:
```bash
git clone <url>
cd boel_production_sync
```
2. Настройте конфигурацию - .env
3.
```bash
docker compose up -d
```
